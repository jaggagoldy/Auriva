## 3. Principle 7 — permanent clinical artifact
Every document persists an **immutable `content_json` snapshot** at generation (branding + meta + body, self-contained). Reprints render the snapshot; corrections create a **new version** (prior superseded, retained). Architecture *allows* View / Print / Download / **Share** / Timeline / Audit — B3 implements **View · Print · Download-PDF · Audit** (`document_generated`) and attaches artifacts to the visit; Share is a reserved viewer affordance → Communication Platform.

## 8. Architecture update
```
Visit → settle (B1) → Invoice/InvoiceLines
        │
        ▼
document-service.generateDocument(type, appointment)      ← CONTENT_ASSEMBLERS registry
   assemble content_json (branding+meta+body)  →  snapshot (immutable)
   version/supersede · unified number · category · audit
        │
        ▼
Document (permanent artifact)  ──GET /api/clinic/documents──▶  Clinical Artifacts (grouped by category)
        │                                                        │
        ▼                                                        ▼
DocumentRenderer (one renderer)  →  Viewer (screen)  +  /print/document/[id] (print / PDF)
Reserved: signature/stamp/footer slots · Share channel · new types (CERT/LAB/RAD/REF/…)
```

## 9. Decision Log
- **Immutable `content_json` snapshot** per version (D-B3-1) — self-contained (branding embedded), so a document never changes if the clinic/record later does.
- **Assembler registry** — a new type is a new `CONTENT_ASSEMBLERS` entry + a body in `BODIES`; the engine, numbering, versioning are type-agnostic.
- **Number stable across versions** — regenerate keeps the number, bumps version; sequence counts version-1 rows per clinic+type+year.
- **Receipt needs a payment** — assembler returns null without one; `ensureVisitDocuments` skips it until paid.
- **One renderer for screen + print** — reuses the `/print` tree (D-B3-3); browser PDF (D-B3-5).
- **Artifacts attached to the visit** at checkout (side rail + completion) — the visit→Clinical-Artifacts relationship the PO named.
