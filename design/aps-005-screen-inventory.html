Screen Inventory

The master list of every screen in Auriva V1 — 96 screens across 9 groups, each with an ID, purpose, primary user, dependencies and future enhancements. This is the single reference for APS-006/007/008 and for engineering estimation. No screen gets designed unless it exists here.

ID Scheme & Priority Definitions

AUTH Authentication · MKT Marketplace · PAT Patient · DOC Doctor · ORG Organization · SET Settings · NOT Notifications · PRO Profile · SUP Support
  • P0  Launch spine — the APS-003 critical path (Identity → Booking → Check-in → Queue → Consult → Prescription) plus what it minimally needs. Auriva cannot launch without these 41.
  • P1  Fast follow — completes each workspace's core value (labs, family, billing, insights overview). Weeks after launch, not months.
  • P2  V1.x — planned and inventoried now so the IA holds, built when the spine is stable (pharmacy ops, claims, trackers).
  • IDs are permanent: never reused, never renumbered. Killed screens keep their ID marked retired. Sub-variants use suffixes (e.g. PAT-003a) only for responsive alternates, never for new purposes.
  • Every screen names its APS-002 template (T1–T8). Modals, drawers and flow steps are not separate screens — they belong to their parent screen.

02 · Rollout View

The P0 spine, in journey order

Read as one patient's visit flowing through the platform — this is also the design order for the screen-design phase and mirrors the APS-003 critical path.

  1. Acquire & book — MKT-001 → MKT-002 → MKT-003/004 → MKT-009 → MKT-010 (with AUTH-001/002 inline)
  2. Patient prepares — PAT-001 → PAT-002 → PAT-003 (live queue) · NOT-001 · PRO-001
  3. Clinic operates — ORG-002 check-in / ORG-003 walk-in → ORG-001 queue board → ORG-005 appointments · ORG-007/008 registry
  4. Doctor treats — DOC-001 queue → DOC-002 workbench (→ Rx) · DOC-003/004 schedule · DOC-007/008 patients
  5. Care lands back with the patient — PAT-008 timeline → PAT-009/010 prescriptions
  6. Supply-side setup that makes it all possible — AUTH-004/005/006 · SET-002/003/004/005 · ORG-010/011 · MKT-013 · SUP-003
Next in Phase 1

APS-004 User Journey Maps (traces the flows above step-by-step, validating this inventory) · then APS-006 Navigation System, APS-007 Workspace Layouts and APS-008 Interaction Patterns. Once those are approved, screen design starts with the P0 spine in the order listed here.
