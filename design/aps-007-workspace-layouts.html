Workspace Layouts

Five reusable layout shells — the structural frames every Auriva screen composes into. Each shell defines its grid, spacing, regions, surface rules and responsive behavior once, so no future screen ever invents its own frame. Built on APS-002 tokens, APS-003 architecture and APS-006 navigation.

01 · Layout System

Shared foundations

Rules that hold across all five shells. Each layout section below only specifies what differs from these defaults.

Canvas & density
  • Page canvas is #F5F7FA; content sits on white surfaces. Never white-on-white (APS-002).
  • Two density modes: Comfortable (Patient, Marketplace, Auth — 16px base type, 48px controls) and Compact (Doctor, Organization — 14px base, 36px controls, 48px table rows).
  • Base unit 4px. All region paddings and gaps are spacing tokens: 16 mobile / 24 desktop card padding, 24 page padding, 32–48 section gaps.
  • Radius: surfaces 12–16px, controls 8px, sheets 16px top corners (APS-002 tokens).
Z-index scale (platform-wide)
0 · contentPage surfaces, cards, tables
100 · chromeSticky top bar, sidebar, bottom tabs
200 · drawerRight drawers, bottom sheets (+ scrim)
300 · dialogModal dialogs, flows-as-modals
400 · palette⌘K command palette
500 · toastToasts, connectivity banner
Overlay standards (all layouts)
  • Drawers — desktop: right-anchored over their list, scrim 45% slate-900, list state preserved (B2/B3). Mobile: bottom sheets with drag handle, snap points 50% / 92%.
  • Dialogs — confirm 420px, task 560px, 16px radius, shadow-lg. Max one dialog over one drawer; never two of either.
  • Flows (T6) — full-screen on mobile, 560px modal on desktop; stepper header, sticky footer CTA, explicit exit confirm.
Empty / loading / error standards
  • Empty states — centered icon-tile (56px) + title + one-line body + single primary action; 48px vertical padding. First-use empties teach; filtered-empties offer "clear filters".
  • Loading — skeleton-first (B6): the shell paints instantly, each region skeletons independently. Spinners only inside buttons. Skeletons mirror the real layout's geometry.
  • Error regions — inline panel with retry, never a blank page; full-page errors reserved for 404/403 (B5).
